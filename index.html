MovieBot

Movie Bot - это телеграм-бот для поиска информации о фильмах, получения рекомендаций, просмотра расписания кинотеатра и поиска фильмов по актерам. Бот использует API Кинопоиска для получения информации о фильмах и парсит сайты кинотеатров для получения актуального расписания.

Используемые технологии:
Python 3
aiogram==3.20.0.post0 (для работы с Telegram API)
BeautifulSoup (для парсинга сайтов кинотеатров)
Requests (для работы с API Кинопоиска)
dotenv (для хранения конфиденциальных данных)
