# Личный сайт-портфолио

Персональный сайт-портфолио веб-разработчика и UX/UI дизайнера.

## О проекте

Современный адаптивный веб-сайт, представляющий профессиональное портфолио с информацией о навыках, проектах и контактах.

## 📁 Структура проекта

```
project/
├── index.html           # Главная страница
├── css/
│   └── styles.css       # Стили сайта
├── js/
│   └── script.js        # Основная логика на jQuery
├── data/
│   └── portfolio.json   # Данные для портфолио
├── img/                 # Изображения и иконки
│   ├── logo.png
│   ├── avatar.jpg
│   ├── telegram-svgrepo-com.svg
│   ├── github.svg
│   └── vk.svg
└── README.md
```

## 🛠️ Технологии

- **HTML5** — семантическая разметка
- **CSS3** — стилизация и адаптивный дизайн
- **jQuery** — динамика и взаимодействие с DOM
- **OwlCarousel2** — карусель навыков
- **Google Fonts** — шрифты Open Sans и Albert Sans
- **Ionicons** — иконки
- **Адаптивный дизайн** — поддержка мобильных устройств

## 💡 Возможности

- Подключена библиотека **jQuery** (через CDN)
- **Форма обратной связи** с модальным окном и симуляцией отправки данных
- **Валидация** полей формы (имя, email, сообщение)
- **Выпадающее меню** для навигации
- **Модальное окно** для формы обратной связи
- **Галерея портфолио** загружается из файла JSON
- **Анимации** (fadeIn, slideToggle, scroll, анимация появления секций и слайдов)
- **Карусель навыков** (OwlCarousel) с кнопками и автопрокруткой
- **Подсветка активного пункта меню** при скролле страницы
- **Кнопка «Вверх»** с плавным скроллом
- Корректная структура проекта (папки js/, data/, css/)

## 📋 Функциональные разделы

1. **Header** — Навигация по сайту с логотипом
2. **About** — Информация о разработчике
3. **Skills** — Навыки с визуализацией прогресса и каруселью
4. **Portfolio** — Примеры выполненных проектов (загрузка из JSON)
5. **Contacts** — Контактная информация, социальные сети, форма обратной связи
6. **Footer** — Копирайт и дополнительная информация

## 🚀 Запуск проекта

1. Клонируйте репозиторий
2. Откройте файл `index.html` в браузере
3. Убедитесь, что структура папок сохранена (css/, js/, data/, img/)
4. Для корректной работы портфолио убедитесь, что файл `data/portfolio.json` доступен
